## 🎯 Choose Your Model

### Quick Decision Tree

```
What's your primary use case?

├─ Microcontroller/IoT?
│  └─ Use v1 (300-500K params, 2-3 MB)
│
├─ Embedded device?
│  └─ Use v2 (1-2M params, 5-8 MB)
│
├─ Desktop/Mobile app?
│  └─ Use v3 (7.67M params, 28 MB)
│
└─ Production/Cloud?
   └─ Use v3.2 (8.3M params, 30 MB) ⭐
```
